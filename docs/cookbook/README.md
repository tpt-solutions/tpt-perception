# Cookbook

Recipes organised by goal rather than by module. Each recipe names a
runnable example in `crates/tpt-perception/examples/` where one exists.

Start with [localise against a fixed map](localise.md) or
[estimate LiDAR odometry](odometry.md), then add
[loop closure](loop-closure.md) when drift matters.

For choosing between algorithms, see [which algorithm should I use](../which-algorithm.md).
